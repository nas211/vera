WHAT IS IN THIS KIT
• A complete first prompt and staged implementation prompts.
• An exact-integer reward-accounting reference and executable Node tests.
• A nondeployable Solidity interface for the new reward-enabled vault.
• Typed boundaries separating native test DOGE from demo USD.
• Configuration placeholders, architecture, flow regressions and acceptance tests.

WHAT THIS IS NOT YET
This is a build scaffold, not a completed Noah project or deployed reward system. No real yield provider is connected. Native testnet rewards must come from a separately funded test-DOGE reserve. Existing immutable vaults need an explicitly chosen new-vault path; they cannot gain reward hooks through a frontend edit. All lending/trading in this design remains DEMO/PAPER.

QUICK LOCAL CHECK
Install/use Node.js, then in the extracted kit run:
  node --test tests/reward-model.test.mjs
No package installation is required for these reference-model tests. They do not test Solidity, wallets, the Vela service or live markets.
